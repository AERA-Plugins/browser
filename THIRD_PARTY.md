# Third-party components

The release payload contains WPE WebKit and supporting libraries, fonts,
certificate data, and Unicode data. These components are not relicensed under
the repository's Apache-2.0 license. They remain governed by their upstream
LGPL, BSD, MIT, font, and data licenses.

The initial runtime uses WPE WebKit 2.52.6. Distributors must preserve the
license files shipped inside the runtime and provide corresponding source as
required by the LGPL. A reproducible source bundle and security-update notes
must accompany production releases.
